# Bubble Studio

Public website: https://iammatthewchan-droid.github.io/bubble-studio/

Bubble and Caption artwork editor. Open the website in a browser; no account is required. This repository contains the deployed static build. Fonts, artwork and editor code are embedded. Drafts are stored locally in each browser.

Current artwork: connected purple bubble tails, 77% bubble-fill opacity, and the existing Caption typography and transparent end fades. The editor supports offline caching after a complete initial download.

Publishing source: main branch, repository root. The app is scoped to /bubble-studio/. Keep that path in the manifest, worker, and HTML when updating.
